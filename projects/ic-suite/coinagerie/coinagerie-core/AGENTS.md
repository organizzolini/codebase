# coinagerie-core

The contracts leaf of the coinagerie package graph: the glossary and vocabulary-report shapes, the anchor, heading, and emoji constants that mark a generated glossary block, and the configuration and glossary errors. Keep it to types, constants, and error classes. It depends on no other workspace package.

## Modules

- `coinagerie-core/` — `coinagerie-core.types.ts` declares `Glossary`, `GlossaryDifference`, and `VocabularyReport`, and `coinagerie-core.constants.ts` holds `COINAGERIE_START_ANCHOR`, `COINAGERIE_END_ANCHOR`, `COINAGERIE_HEADING`, and the error classes.
