## 🪙 Coinagerie

Words the orbit planner uses, regenerated by `coinagerie --write`.

- **kilometer**: The unit every distance is stored in.
- **orbit**: Domain concept the example models: the path a body follows, whose perigee planOrbit returns.
- **perigee**: The closest point of an orbit to the body it circles.
- **plan**: The verb prefix of planOrbit, the function that returns the orbit's perigee distance in kilometers.
- **planner**: The example's module name, orbit-planner.ts, which holds the single planning function exported to callers.
- **src**: The source folder the config includes through its include glob, holding the orbit planner's only TypeScript file.
