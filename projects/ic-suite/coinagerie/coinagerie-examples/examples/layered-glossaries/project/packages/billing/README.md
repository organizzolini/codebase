## 🪙 Coinagerie

- **date**: Part of the dueDate identifier in billing's invoice code, a word the package glossary lists because its code uses it.
- **due**: The day an invoice must be paid by.
- **invoice**: A request for payment, owed in ledger units.
- **src**: The source directory billing's configuration includes with the src/** glob, so its files are scanned for words.
