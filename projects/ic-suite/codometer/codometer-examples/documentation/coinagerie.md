## 🪙 Coinagerie

The words this project uses, regenerated with this project's `coinagerie-check:write` Nx target.

- **border**: CSS property in the theme corpus sample whose bottom edge is set to none, measured as ordinary styling.
- **corpus**: Sample repository of known contents under examples/corpus that every example measures, with its target named Corpus.
- **gap**: Missing piece in an example's documentation, such as its README or index link, named by the shared example-run helpers.
- **modifier**: Composable transform in meanderaw's motif library that adjusts how a Greek meander motif is drawn.
