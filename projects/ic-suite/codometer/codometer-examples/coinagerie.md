## 🪙 Coinagerie

The words this project uses that the root glossary does not define, regenerated with this project's `coinagerie-check:write` Nx target.

- **anchor**: The pair of start and end comment markers that bracket a generated block in a file, so a write replaces only what lies between them.
- **border**: CSS property in the theme corpus sample whose bottom edge is set to none, measured as ordinary styling.
- **bundle**: Compiled JavaScript output in the compiled corpus, which this package calls the equivalent of a shipped bundle.
- **charge**: Fragment of charge or charged, the tax-charging verb in chargeTax and the TypeScript tax utilities corpus sample.
- **convention**: Named naming or layout rule that codometer counts across files, illustrated by the statistics example's per-pattern badges.
- **corpus**: Sample repository of known contents under examples/corpus that every example measures, with its target named Corpus.
- **counter**: Custom statistic that tallies matches of a pattern across files, such as the corpus config's service-file count.
- **hand**: Part of the phrase on hand, the inventory sample's wording for stock held, in its Python module and notebook.
- **inventory**: Python module and Jupyter notebook corpus sample describing stock on hand, with an Inventory class counting holdings.
- **pipeline**: YAML CI workflow sample, pipeline.yaml, whose note above its anchor is the one documentation block measured.
- **place**: Location where a rewrite happens, such as the output example's badge block being replaced in place rather than appended.
- **rewrite**: Verb for updating a generated badge block in place, as the output and custom-render examples rewrite their blocks.
- **self**: Python method receiver in the inventory corpus sample, which the Python analyzer counts as an ordinary parameter.
- **staleness**: Example showing a committed report that no longer matches a fresh measurement, gated by the check reports command.
- **statistic**: Named metric codometer computes, such as a badge count or a comment budget, identified by its label in configuration.
- **unbind**: Refusal outcome when a limit path names nothing measured, shown by the limits examples and their Cannot bind messages.
- **unqualified**: A limit path with no target name in front, which codometer cannot bind unless a default input is set.
