## 🪙 Coinagerie

The words this project uses that the root glossary does not define, regenerated with this project's `coinagerie-check:write` Nx target.

- **arcade**: A pattern characteristic for a unit with no cross or bare dot, stored as a true boolean on each meander row that holds it.
- **batch**: A fixed-size chunk of meander rows that the database service reads or writes at once, sized so one statement stays under Postgres's bind-parameter limit.
- **characteristic**: A measured property of a Code's repeating unit, stored on a meander row in the sparse characteristics column.
- **comb**: A pattern characteristic named for a comb-shaped ink layout, stored as a true boolean on each meander row that holds it.
- **family**: The retired enum column that grouped meanders into families, dropped by the migration that replaced families with characteristics.
- **fork**: A point with three branches of ink, counted per meander as a numeric characteristic.
- **lattice**: The rows-by-columns grid of points and edges that a Code spells, the shape every meander row is stored with.
- **meanderaw**: The project name, the Greek meander data this package stores in the meanderaw Postgres schema.
- **north**: The top side of a lattice point or unit, one of the four compass sides a Code names.
- **swirl**: A pattern characteristic for a unit whose strands wind one way, stored as a true boolean on each meander row that holds it.
- **updatable**: A persistence entity that carries a database-assigned id and audit columns, as the shared PostgresqlUpdatableEntity base provides.
- **whirl**: A pattern characteristic for a unit whose strands wind in a whirl, stored as a true boolean on each meander row that holds it.
