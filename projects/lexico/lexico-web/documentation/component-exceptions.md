# Component Exceptions

Lexico uses the shadcn neutral theme and the shadcn and ReUI component defaults.
Layout classes on our own wrapper elements, and the author cards, the reader
history panel, and the reader's candidate list, take no override of a shadcn
component. These are the deliberate exceptions.

- `src/components/library/library-text-tree/library-text-node.tsx`: the panel takes `p-0` so its row is the full-width collapsible trigger, which takes layout classes (`flex`, `px-4`, `py-2`, `hover:bg-muted/50`) so a long title wraps beside its chevron and the row highlights as a whole.
- `src/components/library/library-author-card/library-text-link.tsx`: the leaf panel takes `p-0` and its link `block px-4 py-2 hover:bg-muted/50`, so the whole panel is the link.
- `src/components/library/library-text-tree/library-text-tree.tsx`: a nested level takes `[--frame-radius:0px]`, so its stacked panels meet the parent's panel with square corners and one border per level; every Frame is `ghost`, `dense`, and `stacked`, so the card's ring is the only outer border.
- `src/components/library/library-author-card/library-author-texts.tsx`: the tree takes `-mx-4`, matching CardContent's padding, so its rows run edge to edge across the card.
- `src/components/library/library-text-tree/library-text-children.tsx`: the status text and buttons take `px-3 py-2` and `m-2`, because they sit in a panel outside any Frame padding.
- `src/components/library/library-toolbar/library-toolbar.constants.ts`: `LIBRARY_FILTER_STRIP` joins the Filter button and every ReUI filter chip into one group, squaring each chip's first and, but for the last chip, last segment and keeping segment text on one line, because each chip is a button group of its own and would otherwise show its rounded border apart from its neighbors; the strip scrolls sideways rather than squeezing.
- `src/components/library/library-toolbar/library-toolbar.constants.ts`: `LIBRARY_STRIP_CHIPS` squares every segment of a strip's chips and overlaps their borders so they join the Group or Sort button as one button group, keeping only the last segment's outer corners round, because each chip wraps its segments in a div the button group does not reach.
- `src/components/library-strip/library-chip/library-chip.constants.ts`: `LIBRARY_TEXT_SEGMENT` gives a read-only segment (a chip label without an action, the page range) the outline button's look without its hover fill.
- `src/components/library/library-paging/library-paging.constants.ts`: `PAGING_DISABLED_ICON` dims only a step's icon, and the step is `aria-disabled` rather than `disabled`, because the stock disabled style fades the whole button and its border out of the joined strip.
- `src/components/library/library-author-card/library-author-card.tsx`: the card content takes `-mb-(--card-spacing)` and the collapsed preview's Frame `-mx-4`, so the frames run flush to the card's bottom and side edges (the card clips the corners); the chevron button takes `aria-expanded:not-hover:bg-transparent`, so the open state does not fill it as selected while hover still does.
- `src/components/library/library-author-card/library-author-texts.tsx`: the load-more row takes `space-y-3 pb-4`, restoring the bottom padding the flush frames removed, only when the row shows.
- `src/components/library/library-author-card/library-author-card.tsx`: the card takes `cursor-pointer` and an `onClick`, so a click anywhere outside a link, button or the expanded texts toggles it; the chevron button stays the keyboard path.
- `src/components/library/library-toolbar/library-toolbar.tsx`: the search takes `min-w-64 flex-1` and each strip `shrink-0`, so the search shrinks to its minimum before a strip wraps to the next line.
- `src/components/library/library-toolbar/library-option-menu.tsx`: the popover takes `w-auto p-0`, to fit the cascader's columns and leave their padding to the cascader.
- `src/components/library/library-grid/library-grid.tsx`: each group's heading and its masonry sit in a `mb-4` section, so the heading spans the width above its cards.
- `src/components/library/library-grid/library-group-heading.tsx`: the heading takes `text-xl font-semibold`, to read as a section title.
- `src/components/forms/forms-table/forms-table.tsx`: cells take `relative h-14` and `border-l`, so the corner abbreviations have room and the columns divide.
- `src/components/lexeme/lexeme-section/lexeme-section.tsx`: the ReUI Marker is the divider row, rendered as a button and given a hairline `span` between label and caret, and takes `cursor-pointer py-1 hover:text-foreground`, so the whole row is the toggle; its label takes `capitalize`, so the lowercase `conjugation` and `declension` read as headings.
- `src/components/lexeme/lexeme-translations/lexeme-translations.constants.ts`: the half-open preview takes `max-h-10 overflow-hidden`, two `leading-5` lines of text, so a first translation that wraps shows alone.
- `src/components/forms/forms-table/forms-table.constants.ts`: a forms Frame takes `-mx-3 [--frame-radius:0px]` to run square from edge to edge of the card's padding; its panels take `p-0` so tabs and tables sit flush with the dividers; the tab list takes `w-full gap-0 rounded-none p-0` and each tab `min-w-0 rounded-none px-0`, with the line variant's selected state re-pointed to `bg-muted`, text `foreground` and no underline, so only the selected tab is filled.
- `projects/common/presentation/src/components/ui/separator.tsx`: the `data-horizontal` and `data-vertical` variants read `data-[orientation=...]`, for the same reason as the tabs, or the rule has no height and never shows.
- `projects/common/presentation/src/components/reui/marker.tsx`: vendored from the shadcn registry unchanged, and exported.
- `src/routes/texts.$slug.tsx`: the reader surface takes `bg-amber-50 dark:bg-background`, a warm paper tone in light mode over the dark theme's near-black.
- `projects/common/presentation/src/components/reui/filters/filters.tsx`: the advanced builder is removed and opt-in through `FiltersAdvanced` children, so basic consumers do not bundle it.
- `projects/common/presentation/src/components/ui/tabs.tsx`: the `data-horizontal` and `data-vertical` variants read `data-[orientation=horizontal]` and `data-[orientation=vertical]`, because Base UI writes `data-orientation` and never the bare attribute, so the stock variants never matched and the tab list rendered as a tall sideways column.
- `src/components/reader/reader-history/reader-history.tsx`: the card takes `h-full min-h-0`, the tab list `w-full shrink-0`, and each tab panel `min-h-0 overflow-y-auto`, so the title and tabs stay fixed while only the entries scroll inside the full-height card.
- `projects/common/presentation/src/components/ui/command.tsx`: the item matches `data-[selected=true]` rather than `data-selected`, because cmdk writes `data-selected="false"` on every other row and the bare variant highlights them all.
- `projects/common/presentation/src/lib/utils.ts`: `cn` re-exports the shared `cn` package instead of defining it.
- `projects/common/presentation/src/styles/globals.css`: the shadcn neutral tokens, plus the `--radius-md` token the shared Button needs and the `--color-border`, `--color-card`, and `--color-muted` tokens the ReUI Frame reads, without which its borders fell back to the foreground color.
