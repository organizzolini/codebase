## 🪙 Coinagerie

The words this project uses, regenerated with this project's `coinagerie-check:write` Nx target.

- **configmap**: Kubernetes object that holds non-secret text, here the dotenv file a job mounts for the CLI.
- **awk**: Text-processing command the helm-unittest installer uses to read the plugin names from `helm plugin list`.
- **connector**: The `cloudflared` process that dials out to Cloudflare and carries the tunnel traffic into the cluster.
- **ingress**: Tunnel rule list that maps a hostname and path to a service; the last rule answers 404.
- **organizzolini**: GitHub organization and the `organizzolini.net` domain that this project's resources live under.
- **proto**: `curl` option that restricts the download to HTTPS in the helm-unittest installer.
- **unittest**: Helm plugin that runs the chart test suites; `helm-test` installs the pinned version.
- **visibility**: Repository setting that makes the GitHub repository public, set to public in the github root.
