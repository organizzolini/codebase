# Known failures

Read when a check, hook, or release run fails and the cause is not obvious. Each row is a symptom seen in this repository and the action that cleared it. Match the symptom, apply the action, and confirm with the check that failed. Facts date from 2026-10; verify a figure against the workflow before relying on it.

## CI and hooks

| Symptom                                                                                                                       | Cause                                                                      | Action                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `sweph` build fails with node-gyp "Permission denied"                                                                         | Flaky native build on the runner                                           | `gh run rerun <id> --failed`, once                                                                                          |
| A trivial test in an unrelated project hits its 5,000 ms default, or a heavy test times out only in CI                        | The runner oversubscribes 4 vCPUs, so wall time runs 5–7x local            | Re-run once. If it repeats, size the test's declared timeout from a **passing** CI run's per-file figure, never a local one |
| `Validate Conventions` or `Comply` fails on assignee, label, or title that is correct on the live pull request                | The check reads the frozen event payload, and a re-run replays it          | Fire a fresh event: `gh pr edit <n> --body-file` with a real change                                                         |
| About two dozen tasks across six packages fail at once with a plugin-worker error                                             | One import cycle crashes the Nx plugin worker                              | Find the cycle with `nx run codebase:lint-codebase`; fix the cycle, not the individual tasks                                |
| `conformetry-validate` fails for many unrelated projects with "out of date with configuration/conformetry.config.ts" | `main` changed the config and the gitignored plugin is stale               | `pnpm exec nx sync`, then retry                                                                                             |
| `dependency-checks` reports a removed dependency as used, or a used one as unused                                             | Stale `dist/*.d.ts` or cached project graph; `.eslintcache` replays it     | Delete the stale `dist`, `pnpm exec nx reset`, retry; `--skip-nx-cache` does not clear it                                   |
| Boundary or DI failure in `codependix --check boundaries` that unit tests and lint never showed                               | A new NestJS provider edge is only exercised by booting the real container | Treat it as a real failure; fix the module wiring                                                                           |
| Passes on macOS, fails on Linux only, around mock clearing or a duplicated `vite`                                             | A catalog range split `vite` and `@vitest/mocker`                          | Reproduce in Docker on `linux/amd64` before chasing macOS leads; **raise to the user** (dependency change)                  |
| Commit hook dies instantly with no output, or a native-module ABI error only inside `git commit`                              | The shell runs Node 26 instead of the pinned Node 24                       | Check `node --version` against `.nvmrc` first                                                                               |
| `eslint` fails on a codometer report after a local codometer run                                                              | The gitignored report is still linted                                      | Delete the generated report, re-run the hook                                                                                |
| Commit adds or drops `projects/JimmyPaolini: {}` in `pnpm-lock.yaml`                                                          | `pnpm exec` reinstalls and strips the entry                                | Start from `main`'s lockfile, commit with `pnpm_config_verify_deps_before_run=false`; never initialize the submodule        |
| A committed report or README diagram is stale after a format pass                                                             | callidescope frames carry byte offsets                                     | Format first, then regenerate (`nx run <project>:callidescope:write`)                                                       |

## Merge and release

| Symptom                                          | Cause                                                                  | Action                                                                        |
| ------------------------------------------------ | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Green `Releases` job, no tag                     | Superseded by a newer commit, or nothing was entitled to release       | Read the job's log lines; watch the tip's run instead                         |
| `Releases` job `cancelled`                       | Job timeout (32 minutes); it leaves no tag, release, or version commit | Re-run once; a second timeout is a **raise to the user**                      |
| Release commit `Unverified` on GitHub            | semantic-release forces its own committer email                        | Expected; not a defect                                                        |
| Tag push rejected                                | GitHub refuses a push updating more than 6 refs                        | The release script batches 6 and retries; a later run pushes any missing tags |
| Queue ejects a pull request that was green alone | `main` moved underneath it, or a gate sees the combined merge          | Merge `main` in (step 2), re-run checks locally, re-enqueue                   |
