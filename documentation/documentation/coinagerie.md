## 🪙 Coinagerie

The words this project uses, regenerated with this project's `coinagerie-check:write` Nx target.

- **bookkeeping**: Wiki files that record when a refresh last ran, never what the wiki says, so a change to only them opens no pull request.
- **ephemeris**: Table of astronomical positions that caelundas computes, which the generated wiki describes.
- **meander**: Greek key border motif that meanderaw draws as SVG, which the generated wiki describes.
- **patience**: Longest wait for a rate limit reset that a refresh accepts before it stops retrying.
- **swiss**: Short for Swiss Ephemeris, the astronomy library caelundas uses to compute positions locally.
