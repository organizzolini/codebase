## 🪙 Coinagerie

The words this project uses, regenerated with this project's `coinagerie-check:write` Nx target.

- **db**: The file extension of an Nx task database, such as the `other-v3.db` a test writes beside the cache.
- **derivation**: A command that computes a generated file or block from other files in the repository, so its `check` finds drift and its `write` repairs it.
- **overlong**: A skill description holding more words than the `skill-descriptions` check allows, which it names with its word count.
